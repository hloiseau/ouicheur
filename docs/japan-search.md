# Parcours Japon retiré

Le parcours ChatGPT / Sendico a été retiré le 3 octobre 2026 à la demande du propriétaire, pour recentrer Ouicheur sur une utilisation grand public. Il n’est plus proposé dans les formulaires, les imports, les cartes ou les fiches cadeaux.

La migration historique `004-gift-japan-search.sql` et sa colonne SQLite sont conservées pour la compatibilité des bases et des sauvegardes existantes. Cette ancienne valeur n’est plus utilisée ni exposée par les vues de cadeaux. Le code et les anciens critères restent consultables dans l’historique Git.
