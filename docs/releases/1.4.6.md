# Ouicheur 1.4.6

Cette version met à jour les dépendances de production signalées par l’audit de sécurité :

| Dépendance        | Version retenue | Motif                                                                |
| ----------------- | --------------- | -------------------------------------------------------------------- |
| Next.js           | 16.4.3          | Correctifs d’exécution de code à distance et de déni de service      |
| Nodemailer        | 10.2.1          | Correctifs d’analyse des adresses de destinataires                   |
| Zod               | 4.6.7           | Contrôle de la taille des collections avant leur validation          |
| Undici, indirecte | 7.30.1          | Correctifs des parseurs réseau et de l’intégrité des sous-ressources |
| React / React DOM | 19.3.1          | Versions de maintenance synchronisées                                |

Les références précises des avis sont fournies par `npm audit`. L’audit des dépendances de production de sévérité haute ou critique reste obligatoire avant publication ; aucun avis n’est ignoré et aucun seuil n’est abaissé.

Aucune migration SQLite ou PostgreSQL, nouvelle variable d’environnement ou modification intentionnelle de la présentation. Les parcours existants sont revérifiés par les contrôles TypeScript, tests métier, contrats PostgreSQL, tests navigateur et recettes Docker AMD64/ARM64.

La version stable est publiée par la procédure existante après validation des images exactes. Cette mise à jour ne revendique pas de nouvel essai sur un NAS physique ou sur Safari/iOS. Conserver la sauvegarde habituelle avant la mise à jour de son instance.
